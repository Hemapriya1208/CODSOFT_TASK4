# CODSOFT TASK 4 – Customer Data Analysis

## Project Overview

This project focuses on analyzing customer information to understand purchasing behavior and identify valuable customer groups.

## Objectives

- Analyze customer purchasing patterns.
- Segment customers based on age, location, and buying behavior.
- Identify valuable customer groups.
- Generate useful business insights.
- Suggest marketing strategies based on the analysis.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights

The analysis helps identify customer segments, understand their purchasing behavior, and find opportunities for better-targeted marketing.

## Conclusion

This project demonstrates how customer data can be transformed into meaningful insights to support data-driven business decisions.
